# Handover KZ

Мобильное приложение для iOS/iPadOS для составления актов приёма-передачи квартиры с фотофиксацией состояния и сравнением «до/после» между заселением и выселением.

## Описание

**Handover KZ** — это профессиональный инструмент для риелторов, управляющих недвижимостью и арендодателей в Казахстане. Приложение помогает документально зафиксировать состояние квартиры при заселении и выселении арендатора, автоматически выявляет ухудшения и формирует PDF-отчёты для обоснования удержаний из залога.

## Основные функции

- 📋 **Создание актов приёма-передачи** с полной информацией об объекте и сторонах
- 🏠 **Осмотр помещения** по комнатам и элементам с оценкой состояния
- 📸 **Фотофиксация** каждого элемента через камеру или галерею
- ✍️ **Электронные подписи** арендодателя и арендатора
- ⚖️ **Автоматическое сравнение** состояния «до/после»
- 🔍 **Выявление ухудшений** с визуальными индикаторами
- 📄 **Экспорт в PDF** актов и сравнительных отчётов
- 💾 **Офлайн-работа** — все данные хранятся локально на устройстве
- 🌐 **Двуязычный интерфейс** — русский и казахский

## Технические характеристики

### Требования

- iOS/iPadOS 17.0 или новее
- Swift 6.0+
- SwiftUI

### Архитектура

Проект состоит из двух основных частей:

1. **FieldDocsCore** — Swift Package с общим ядром:
   - Модели данных (Project, Party, Photo, Signature, ConditionState)
   - Доменная модель (HandoverCase, HandoverRoom, HandoverElement)
   - Репозиторий для хранения данных
   - PDF рендерер для генерации отчётов

2. **HandoverKZ** — основное iOS приложение:
   - SwiftUI интерфейс
   - Дизайн-система (MSColor, MSFont, MSSpacing, MSRadius)
   - Экраны для работы с актами
   - Модуль фотографирования и подписей

## Функциональные требования

### Основные модули

1. **Мои акты** — список всех созданных актов с фильтрацией и сортировкой
2. **Создание акта** — ввод данных об объекте, сторонах и залоге
3. **Осмотр** — добавление комнат, элементов, фото и оценка состояния
4. **Подписи** — цифровая подпись пальцем на экране
5. **Сравнение** — автоматическое выявление ухудшений между фазами
6. **Экспорт PDF** — формирование профессиональных отчётов

### Особенности для КЗ

- Идентификация сторон по **ИИН** (12 цифр)
- Все суммы в **тенге** (₸)
- Локализация на **русский** и **казахский** языки
- Соответствие местным требованиям к документообороту
